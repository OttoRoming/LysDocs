# Lysdocs

Skapa gärna pull-request om du vill bidra!

Mer information går att hitta på https://starlight.astro.build/

## Hur man utvecklar

1. Installera beroenden
```
npm i
```

2. Starta dev server
```
npm run dev
```

3. Kolla efter linting fel
```
npm run check
```

4. Försök använda autofixes
```
npm run fix
```
