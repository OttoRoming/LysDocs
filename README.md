Lysdocs utvecklas nu på <https://forge.lysator.liu.se/lysdocs/lysdocs>

## Hur man utvecklar

1. Installera beroenden

```text
npm i
```

2. Starta dev server

```text
npm run dev
```

3. Kolla efter linting fel

```text
npm run check
```

4. Försök använda autofixes

```text
npm run fix
```
