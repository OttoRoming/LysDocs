# Lysators hemsida

Numera är Lysators hemsida statiskt genererad med [`zola`](https://www.getzola.org/documentation/getting-started/overview/). Den har (precis som LysDocs) öppen källkod, och tar gärna emot bidrag från dig!

För att bidra, gå till [repo:t](https://git.lysator.liu.se/www/hemsida) och läs igenom `README.md`. Du kan utveckla helt lokalt, och sen skapa en Merge request med dina önskade ändringar!
