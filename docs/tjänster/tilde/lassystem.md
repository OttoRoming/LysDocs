# Låssystem till lokalen

Det är tillåtet att vistas i Lysators lokal när som helst på dygnet. Gemene Lysit kan därför råka besöka
`~` när ingen annan är där för att låsa upp. För att åtgärda detta har ett antal Lysiter plockat fram ett låssystem
som är tillgängligt för alla medlemmar.

!!! warning "Portkod på kvällar"
    Utöver lås in till lokalen så finns den en portkod in till HusEtt som behövs kvällstid. Denna får lysiten efter att ha loggat in nedan

För att låsa upp dörren till lokalen ska du:

1. Besöka[^] [lock.lysator.liu.se](https://lock.lysator.liu.se)
2. Logga in.
3. Trycka på `Unlock` för att öppna rummet.
4. Trycka på `Lock` när du lämnar rummet för att låsa efter dig.

[^]: Det finns också en smidig NFC tagg och QR-kod som sitter på dörren in till ~
