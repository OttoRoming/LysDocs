# Låssystem till lokalerna

Det är tillåtet att vistas i Lysators lokaler när som helst på dygnet. Gemene Lysit kan därför råka besöka
ˇ när ingen annan är där för att låsa upp. För att åtgärda detta har ett antal Lysiter plockat fram ett låssystem
som är tillgängligt för alla medlemmar.

För att låsa upp dörren till respektive lokal ska du:

1. Besöka [admin.lysator.liu.se](https://admin.lysator.liu.se)
2. Logga in.
3. Navigera till rubriken "Lokaler" och välja rummet du vill låsa upp.
4. Trycka på "Unlock" för att öppna rummet.
5. Trycka på "Lock" när du lämnar rummet för att låsa efter dig.
