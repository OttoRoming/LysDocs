För att slippa _bloated-ass_ grafisk Forticlient VPN, kan med [`openfortivpn`](https://github.com/adrienverge/openfortivpn) användas istället.

1. Installera enligt [instruktioner på repo](https://github.com/adrienverge/openfortivpn#installing):

2. Anslut genom att köra (**med root-privilegier!**):

```sh
openfortivpn remote.edu.liu.se --saml-login
```
