title: Gitlab
---

Lysator hostar en egen git instans som kan hittas på
[git.lysator.liu.se](https://git.lysator.liu.se). Där hittar du repo för
hemsidan, lysdocs, samtliga konfigurationer för våra machiner och mycket mer.
Gitlaben kan användas både till personliga projekt, som spegel av repo eller
till Lysator projekt.

Eftersom våran git är öppen till vem som helst behöver du skapa ett konto där
innan du kan använda den.

## Grupper

Lysators egna repo är organiserade som grupper för att underlätta att man hitta
rätt:

- [Lysator](https://git.lysator.liu.se/lysator): Lysatorspecifika projekt
- [Puppet](https://git.lysator.liu.se/lysator/puppet): Konfigurationer till
  Lysators system
- [Nix](https://git.lysator.liu.se/lysator/nix): Konfiguration till NixOS
- [Lysfika](https://git.lysator.liu.se/lysfika): Konfiguration till NixOS
  system på föreningen
