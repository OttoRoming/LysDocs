[SPARC](https://en.wikipedia.org/wiki/SPARC) (Scalable Processor ARChitecture)
är en RISC-arkitektur ursprungligen utvecklad av Sun Microsystems under mitten
av 1980-talet. Oracle köpte upp Sun och annonserade under 2017 slutet av
SPARC:s utveckling.

# Maskiner
Xenofarm driftar idag exklusivt 64-bitars-versionen av arkitekturen, men den
äldre 32-bitars-varianten kan tillkomma vid efterfråga.

## Hyperion
| Komponent       | Detaljer                            |
|-----------------|-------------------------------------|
| Operativsystem  | Oracle Solaris 11.4                 |
| Modell          | Oracle SPARC T4-1                   |
| Processor       | UltraSparc T4, 8 Kärnor, 64 Trådar  |
| Minne           | 256 GB                              |
| Placering       | BAR-hallen                          |
| Namngiven efter | Titanen Hyperion i grekisk mytologi |
| Ansvarig root   | kacper                              |

Hyperion agerar LDOM-host till Selene, Eos, och Helios. Den delar därför sin
processor och minne med dem. Antalet kärnor och minne som ges till varje LDOM
kan justeras, så tveka inte på att be [Kacper](mailto:kacper@lysator.liu.se)
justera dessa efter dina behov.
