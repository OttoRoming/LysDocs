## Användningsområden

Speciellt lämplig för tunga, parallella jobb, såsom kompilering. Monterar hemdisk och mailkataloger samt det delade Lysator-filsystemet. 

[Apptainer](https://apptainer.org/) kan användas för att köra OCI-containers likt docker.

## Pakethantering

Då Volton kör NixOS kan varje användare tillfälligt få tillgång till valfria
paket. För att sättas i ett skal med tillgång till ett paket, `$PAKET`, skriv:

```bash
nix-shell -p $PAKET
```

eller:

```bash
nix shell nixpkgs#$PAKET
```

För att se vilka paket som finns, sök i nixpkgs på
[search.nixos.org/packages](https://search.nixos.org/packages).
