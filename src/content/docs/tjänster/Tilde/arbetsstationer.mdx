## Logga in

På arbetsstationerna kan du logga in med ditt Lysator konto precis som på [CPU Servrarna](/tjänster/cpu-servrar).

## Paket

Om paket som önskas saknas på arbetsstationerna kan man kontakta ansvarig root via mail.

<Aside type="tip">
    Det går att lägga till paket på NixOS maskinerna administrerade av Kacper genom att
    [skapa en merge request på Lysator Nix Gitlab repot](https://git.lysator.liu.se/lysator/nix/nixos).
</Aside>
