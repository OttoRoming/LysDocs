Detta är en guide över olika sätt att använda din Lysatorspecifika e-post.

<Aside type="caution" title="Sätt e-postlösenord!">
      För att överhuvudtaget kunna logga in på ditt e-postkonto måste du [sätta ett lösenord](/kom-igång/som-ny-medlem/kom-igång-med-epost/#sätt-lösenord).
</Aside>

## Webmail

[webmail.lysator.liu.se](https://webmail.lysator.liu.se) låter dig läsa skriva och organisera din e-post i webbläsaren. Vi kör för tillfället [Roundcube](https://roundcube.net/) som webmail-klient.

Du loggar in med ditt användarnamn och det lösenord du satt i [https://admin.lysator.liu.se/mail](https://admin.lysator.liu.se/mail).

## `IMAP`, `POP` och `SMTP`

Med dessa kan du ansluta exempelvis [thunderbird](https://www.thunderbird.net) eller andra mailklienter.

Det rekommenderas att använda TLS-kryptering om du ska ansluta till dessa.

Om du väljer en "okrypterad" anslutningstyp måste du använda STARTTLS för att kunna logga in.

Som användarnamn används ditt vanliga användarnamn.
Som lösenord ska du använda det lösenord du satt för mail i [admin](https://admin.lysator.liu.se/mail).

| Anslutningstyp | Server                | Port | Kryptering |
| -------------- | --------------------- | ---- | ---------- |
| **Inkommande** |                       |      |            |
| IMAP           | `imap.lysator.liu.se` | 143  | STARTTLS   |
| IMAP/TLS       | `imap.lysator.liu.se` | 993  | TLS        |
| POP3           | `pop.lysator.liu.se`  | 110  | STARTTLS   |
| POP3/TLS       | `pop.lysator.liu.se`  | 995  | TLS        |
| **Utgående**   |                       |      |            |
| SMTP           | `mail.lysator.liu.se` | 26   | STARTTLS   |
