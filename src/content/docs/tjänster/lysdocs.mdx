På LysDocs hittar du information om Lysators tjänster,
guider för diverse teknik och tips för hur man kommer igång som ny medlem.
Du är varm välkommen att bidra till att förbättra lysdocs om du har ideér.

![Drawing Hands](./DrawingHands.jpg)

## Lägg till och redigera nya artiklar till datorhandboken

LysDocs utvecklas på
[Lysator Forge](https://forge.lysator.liu.se/LysDocs/LysDocs).

### Utvecklingsmiljön

<Steps>
1. Klona ner handboksrepot [härifrån](https://forge.lysator.liu.se/lysdocs/lysdocs) med
    <Tabs>
        <TabItem label="HTTPS">
            ```bash
            git clone https://forge.lysator.liu.se/lysdocs/lysdocs.git
            ```
        </TabItem>
        <TabItem label="SSH">
            ```bash
            git clone ssh://git@forge.lysator.liu.se/lysdocs/lysdocs.git
            ```
        </TabItem>
    </Tabs>

2. Navigera till toppen av den nedhämtade katalogen och kör
    ```bash
    npm i
    ```
   för att installera alla beroenden

3. För att starta utvecklingsservern kör
    ```bash
    npm run dev
    ```

4. Öppna nu din webbläsare och navigera till http://localhost:4321/ för att se sidan lokalt

5. För att formattera sin mdx kod kör
    ```bash
    npm run fix
    ```

6. Mer information om Starlight går att hitta på https://starlight.astro.build/

</Steps>

### Sidredigering

<Steps>
    1. Checka ut en egen gren med
        ```bash
        git checkout -b *<namn på din gren>*
        ```
    2. Gör dina önskade ändringar, spara dem med `git add *<filnamn>*` och `git commit`.
    3. Tryck upp dina önskade ändringar till gitlab med `git push` och logga in på https://forge.lysator.liu.se/lysdocs/lysdocs för att skapa en pull request.
    4. Din request ses över och mergas till eller nekas från master.
</Steps>

### Skapa nya sidor

<Steps>
    1. Skapa en `.md` eller `.mdx` fil i `src/content/docs/[kategori]/`.
    2. Ge den en frontmatter med en titel
        ```mdx
        ---
        title: "Min nya sida"
        ---

        Hej detta är min nya sida
        ```
</Steps>

### Hantera system

System finns i `src/content/systems` och söks efter med glob mönstret
`**/*.mdx`. Det gör alltså ingen skillnad var man placerar systemet i
`src/content/systems` men att ha krockande filnamn skapar för nuvarande problem
med att flera system får internt samma ID i Astro.

#### Frontmatter schema

Varje system ska ha en frontmatter för systemets specs och det uppskattas om man
dokumenterar sina system så utförligt som möjligt. Detta schema definieras i
`src/content.config.ts`.

| Nyckel         | Beskrivning                                 |
| -------------- | ------------------------------------------- |
| title[^1]      | Namnet på systemet                          |
| os             | Operativsystem                              |
| arch           | Arkitektur                                  |
| model          | Modell                                      |
| cpu            | Processor                                   |
| ram            | Mängd och typ av minne (tex. `128 GB DDR4`) |
| gpu            | Grafikkort                                  |
| placement      | Placering, rum och rack                     |
| namedAfter     | Namngiven efter                             |
| admin          | Ansvarig root                               |
| sshFingerprint | PGP signerat SSH fingeravtryck              |
| category[^1]   | Systemets kategori                          |

[^1]: Obligatoriskt fält

Det går också att använda sig av fält som Starlight definierar.
`pagefind: false` kan vara användbart för att gömma systemet från att sökas
efter.

#### Kategorier

Systemets kategori bestämmer var i LysDocs systemet kommer att synas för
användare. Lista på kategorier finns i `src/systems.ts` i javascript objektet
`systemCategories`. Varje kategori definierar vilken [topic](#topics) den
tillhör samt vilken sidebar grupp som ska befolkas med systemen. Kom ihåg att
det måste finnas en `index.mdx` så att Starlight automatiskt genererar sidebar
gruppen som ska befolkas.

Kategorier går också att använda för att skapa länk rutnät över en
systemkategori ([Exempel](/tjänster/xenofarm/sparc)).

```mdx
import SystemGrid from "@components";

<SystemGrid category="[KATEGORI]"/>
```

### Topics

*Topics* är de fälten som syns i toppbaren på sidan, dessa hanteras med
starlight pluginen `starlight-sidebar-topics-plugin`

#### Skapa nya topics

<Steps>
    1. Skapa en katalog i `src/content/docs`.
    2. Hitta en passande ikon för kategorin.
        Lista på tillgängliga ikoner går att hitta i [Starlights dokumentation](https://starlight.astro.build/reference/icons/#all-icons).
    2. Lägg till din kategori i `astro.config.mjs` under `starlightSidebarTopicsPlugin`.
        Exempel:
        ```js
        {
          id: "[id]"
          label: "[titel]",
          link: "/[katalog]/",
          icon: "[ikon]",
          items: [{ autogenerate: { directory: "[katalog]" } }],
        }
        ```
</Steps>
